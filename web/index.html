Certificate trust
Checking how this machine establishes trust…
How your credential is handled. It is encrypted with a key file unique to this install and never leaves this machine except to authenticate against Tenable. It is never written to logs. This protects against casual disk inspection and stray backups — it is not protection against someone who can already read your home directory. On a shared machine, treat the credential as recoverable and rotate it in Access Management if you suspect exposure.
